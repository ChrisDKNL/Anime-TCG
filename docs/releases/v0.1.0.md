# v0.1.0: first production release (Sprint 1)

Candidate: **`v0.1.0-rc.1`** on `main` commit `6ac7ccb`, `main` CI green. Acceptance (http://127.0.0.1:8180) runs `360dd85`, which has the same app content: every merge after it touched only docs.

## What is in this release

- **Accounts:** register with an invite code, log in and out, rename, change password, delete (#23, #25); rate-limited forms show the wait (#39).
- **Pages:** every screen at its own address (#30); the redesigned landing page and the public `/demo` page (#42, #57).
- **Packs, on the server** (#28, #31, #38):
  - six tiers, with slot floors, pity at 300, Enchanted every 10th and Radiant 1 in 2 500;
  - the allowance of one pack every 10 minutes, up to 3;
  - opening at `/packs/open` (#57).
- **Collection** (#41): search, filters, sort, pages, the Series view, the card dialog.
- **Economy:**
  - the Karma ledger, Recycle for Karma and genre shop packs at `/shop` and `/shop/open` (#40, #51, #55);
  - the player market with listings, buying, the 5 % fee and the 7-day limits (#53, #60);
  - the owner commands `audit-ledger` and `audit-market`.

## On approval (the local session)

The conditions M1–M8 are in `docs/security-log/2026-10-31-production-release.md`. Production never uses the acceptance watcher's checkout `C:\ProgramData\AnimeTCG\src` or its compose project `src`, because the watcher moves that checkout to every new app change on `main`.

1. Tag `v0.1.0` on `6ac7ccb`.
2. Owner: limit `C:\ProgramData\AnimeTCG` to SYSTEM, Administrators and the owner (M4), and confirm the Cloudflare settings (M7).
3. Clone the tag into its own checkout, `C:\ProgramData\AnimeTCG\production\tcg`, and check that it is at `6ac7ccb` (M2).
4. Write `C:\ProgramData\AnimeTCG\production\.env.production.local`, outside every checkout, with production's own `POSTGRES_PASSWORD`, `APP_DB_PASSWORD`, `SESSION_SECRET` and `INVITE_CODES` (never acceptance's), plus `WEB_ORIGIN=https://tcg.private-0118.nl`, `PRODUCTION_PORT=8190` and `ACCOUNT_CAP=10` (M3, M5).
5. In the production checkout: `TAG=v0.1.0 docker compose -p anime-tcg-production --env-file ../.env.production.local --profile production up -d --build --wait`. Check that only `127.0.0.1:8190` is published (M5).
6. Load the card snapshot into production with the owner command, then smoke-test on loopback.
7. Replace the `tcg.private-0118.nl` block in the native Caddyfile with the review's block: the real visitor address from Cloudflare's ranges only, and HSTS (M1). Back the file up, validate, then reload. Run the forged-header probe on loopback and the two-network probe.
